# Employee Analytics Dashboard – Power BI

**Project Overview**

Developed an interactive Employee Analytics Dashboard using Microsoft Power BI to analyze employee demographics, salary distribution, departmental composition, performance, and workforce information. The dashboard helps users explore employee data through visual reports and interactive filtering.

**Tools & Technologies**
- Microsoft Power BI
- Power Query for data preparation
- Data Visualization and Reporting
- Employee Data Analysis

**Key Features**
- Employee distribution by department and job role.
- Salary analysis across departments.
- Employee gender and age distribution.
- Employee performance analysis.
- Workforce analysis by location and joining date.
- Interactive visuals to explore employee information.

**Skills Demonstrated**
- Data cleaning and transformation.
- Creating interactive dashboards.
- Selecting appropriate charts and visualizations.
- Analyzing workforce trends.
- Presenting data-driven insights.

**Project Objective**

To transform employee data into meaningful visual insights that support workforce analysis and help management understand employee composition, salary patterns, and performance.

**Outcome**

Created a multi-page Power BI dashboard that organizes employee information into an interactive reporting experience, demonstrating practical skills in data analysis and business intelligence.
